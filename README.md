

# PeeraniShop – E-commerce SQL Project

PeeraniShop is a Pakistan-based e-commerce database project designed to manage customers, products, orders, order items, and payments.

## Project Overview
This project demonstrates a relational database structure for an online store, along with sample data and SQL queries for business analysis.

## Database Tables
- Customers
- Products
- Orders
- Order Items
- Payments

## Key Features
- Database design and table relationships
- Primary and foreign keys
- Sample Pakistani customer and product data
- Order and payment management
- Business analysis using SQL queries

## SQL Analysis
- Total revenue
- Revenue by product
- Top customers by spending
- Best-selling products
- Cancelled orders
- Revenue by payment method
- Customers by city
- Products with low stock

- MySQL
